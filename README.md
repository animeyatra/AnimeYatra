# AnimeYatra

AnimeYatra is an anime streaming website built with React, TypeScript, and Vite.

## Features

- 🎬 Anime browsing
- 🌐 Multiple audio/language tracks
- 🔥 Trending anime
- 📅 Schedule
- ❤️ Watchlist
- 🔎 Anime search
- 🛡️ Admin panel
- 📱 Responsive design

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Lucide React

## Run Locally

Install dependencies:

npm install

Start the development server:

npm run dev

## Environment Variables

Create a `.env.local` file and add your required environment variables.

Do not upload `.env.local` or private API keys to GitHub.

## Deployment

The project is deployed using Vercel and connected to GitHub.

Changes pushed to the main branch can trigger a new Vercel deployment.
